# 使用指南

## 第一次使用

首次打开 FileMaid 时创建唯一的管理员账号。随后进入“设置 → 系统”，点击“重新检查”，确认 SQLite、FFprobe 和媒体根目录均可用。

建议第一次保持媒体目录只读，并只放入少量可丢弃的测试文件。

## 整理文件

1. 在“整理”页选择服务器目录。
2. 点击“扫描目录”，等待后台任务结束。
3. 检查伴随文件、识别类型、标题、年份、季和集数。
4. 点击“自动匹配”，或点选单个文件手动选择元数据候选。
5. 直接编辑不合适的新文件名；也可以勾选多行后批量查找替换。
6. 选择移动、复制或硬链接。
7. 按需开启 NFO、海报或背景图。
8. 点击“干跑校验”，解决页面列出的冲突。
9. 最后确认并执行。服务器会再次验证同一个不可变计划。

扫描、预览和执行都在后台运行。刷新页面后任务仍可继续查看；尚未执行的整理草稿保存在当前浏览器中。

## 三种文件操作

- **移动**：把源文件移动到目标位置，适合正式整理。
- **复制**：保留源文件并创建副本，需要额外磁盘空间。
- **硬链接**：源和目标共享同一份文件数据，通常要求位于同一文件系统。

目标已存在时默认不会覆盖。建议不要把冲突策略改成跳过，除非你理解批次中部分文件未执行的影响。

## 历史与撤销

“历史”页按任务批次展示逐文件结果，可以按路径、成功状态和操作类型筛选。

撤销移动会把文件移回源位置；撤销复制或硬链接会删除目标。只有源、目标和路径状态仍然安全时，撤销才会执行。NFO 和封面也会独立记录。

## 实时日志

“日志”页显示扫描、预览、执行和系统信息，支持级别筛选、搜索、暂停和清空当前视图。日志只在内存中保留有限数量，重启服务后清空；常见密钥和认证字段会自动遮盖。

报告问题前，可以按“警告”或“错误”筛选并复制相关内容。仍需检查其中是否包含私有文件名或路径。

## 常见问题

### 执行按钮不可用

确认 Docker 挂载使用 `:rw`，并且 `FILEMAID_ROOT_WRITABLE=true`。修改后重新创建容器。

### FFprobe 不可用

官方镜像已包含 FFprobe。自定义运行方式需要自行安装 FFmpeg，并在设置或 `FILEMAID_FFPROBE_PATH` 中配置路径。

### 搜不到元数据

先在“设置 → 元数据源”测试连接。TVMaze 和 AniDB 无需 Key；其他提供器需要自己的凭据。代理也在设置页配置。

### 忘记密码

参阅 [升级与恢复](upgrade-and-recovery.md)。FileMaid 不提供无需登录的远程密码重置入口。
